# 事件蓝本

**这是默认值，不是锁定值。** 实际启用的事件清单在 `config/events.md`——那份归模型，随便改。
`config/events.md` **不存在时就用本文件**；想恢复默认，删掉工作清单即可。

出处：`codex/eva.md`（136 个副官事件的全量表，含引擎原文、优先级、排队语义）。
本文件只记**选哪些、为什么**。

## 一条判据

**事件是拿来打断模型的，不是拿来记录状态的。** 一次唤醒就是一轮 LLM 调用，所以只留两类：

- **瞬时动作**：发生了就没了，事后从状态里读不出来（被渗透）。
- **「刚刚变了」**：当前快照答不出「什么时候变的」（有玩家被击败）。

**当前局面能回答的，一律不做事件**，让模型自己看状态：单位阵亡、建造完成、升级、
占领与进驻、指令反馈（意图状态机制已经在回报）、间谍机与增援。

## 启用

### 被渗透与破坏（11）

建筑被渗透 · 被渗透：科技被窃／雷达被破坏／资金被窃／电力被破坏 · 科技被窃 ·
雷达被破坏 · 资金被窃 · 电力被破坏 · 火力科技被窃（我方升级）· 装甲科技被窃（我方升级）

理由：**别人的动作打到我身上**，我看不到过程；状态里只留一个布尔 flag，连什么时候被
渗透的都读不出来。

### 经济与电力（2）

电力不足 · 资金不足

理由：它们是**判定**而不是数字——状态里只有 `power_drain` 与 `money`，够不够要看上下文。

矿车被攻击 / 离线**不在此列**，归到「单位被攻击」，由模型自己处理。

### 联盟与外交（1）

有玩家被击败

理由：**外交格局刚刚变了**，当前快照看不出「刚刚」。**必须带主语**——是哪个玩家
（引擎里是 `house`，映射成人能读的国家 + 颜色 + 是否 AI）。不带主语就没有用。

## 搁置：拿不到的

下面两类引擎**无条件全图播报**，而我们的观测按迷雾过滤，所以**合成不了**：

- 17 个全图事件：超武的侦测与激活（核弹、铁幕、超时空、闪电风暴、心灵控制器、
  基因突变器、力场护盾）、信标侦测、四类敌方编队侦测。
- 87 条出厂报告：基洛夫、自爆卡车、天启、黑鹰……**含用户明确要的基洛夫与自爆卡车**。

**后果是功能缺失而不是错误**：基洛夫要等飞进视野才由「遇敌」发现，**没有提前预警**——
而出厂报告的意义恰在「看见之前」。

**唯一的路是让引擎暴露它自己的播报队列**（改 `ra2yrcpp` 的 C++ 并重编 DLL）。
那会让 104 个一次性全拿到，且视野语义完全正确（引擎已经判好了）。**暂时不做。**

## 也搁置：战役专用（27）

任务目标、倒计时、通讯、胜负、地形发现、桥梁修复。一局对战里不会出现。

`CloneVat`），且 `ForceShieldYur` 与 `ForceShieldYuri` 重复。将来若要用，得先和
`rulesmd.ini` 的类型名对照一遍。
