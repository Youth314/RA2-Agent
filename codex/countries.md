# 国家

一局的参战方是**国家**，不是阵营。每个国家能造的东西 = **本阵营的共用清单** + **自己的特有项**。

阵营共用在 [`units.md`](units.md) 与 [`buildings.md`](buildings.md) 的对应章；各国特有的都在这里。
