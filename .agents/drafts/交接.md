## 挂载形态

**一个 Agent，不拆模式**：对战与复盘在同一段上下文里，故不为「对战」和「写技法」分设两个 Agent。目标形态是现有编码能力 + 五个游戏工具 + 写技法的 skill。

已知的三条约束：DSH 启动时会先用临时探针进程列工具，故**服务启动时不能要求游戏在线**；单次工具调用默认 60 秒超时，故 **`call` 必须立刻返回**；**一个进程独占游戏连接**，模型不自己开连接，也因此不把挂载放到 profile 级。

  `stale_frames`（1800 帧≈30 秒）直接丢；合并文案也不再产生 `- -` 与空条目。
- **点名建筑「到位但不输出」**（实机）：三次用 `focus_fire` 点名敌方电厂/兵工厂，
  结果都是 `satisfied｜到位 N 失败 0`，而**建筑没掉血**。原因是 `chase` 那条路发的是
  `MoveTo`，单位走到就判「到位」并结算，**从没轮到发 `Attack`**。真有效的做法（玩家
  实测）是贴到目标脸上让自动接战打。要改的地方在 `focus_fire` 与运行时的结算：追到
  目标附近之后必须**继续活着并发 `Attack`**，不能一到位就结算。
- **`retreat` 回报假失败**（实机）：`retreat#2d1c59615e39｜failed｜到位 0 失败 7`，但
  7 台全部安全撤回原位、零损失。撤退途中被敌人蹭到时，单位的 `goal` 与卡住计时会把它
  推成 `UnitMode.FAILED`（`_stuck` 那条路），而「其实已经到家」不被认。要改的是
  `micro._settle` / `_stuck` 的判据：结算时对 `FAILED` 的单位再核一次「是否已落在
  目标格宽容范围内」，落在里面就记到位。**改动落在结算判官上，得先有复现（离线造一个
  「路上被打停、随后自行走到目标格」的序列）再动。**
- `scout_area` 已改成持续侦察（`max_frames` 上限 + 豁免等待收割），但**还没在真局里验过**。
- 唤醒投递的子 agent 修复已进 `dsh-wake/lib/`，但**要重启 DSH 才生效**，重启后需实测一次「空闲中的玩家 agent 被游戏事件叫醒」。

## 陷阱

均为已踩过的坑；真机操作类的坑见[真机测试手册](../notes/验证/真机测试手册.md#九踩坑清单)，本节不重复。

1. **任务类动作用 `UnitOrder`，不要用 `MissionClicked`。** 后者无条件调用 `get_map_cell`，而前者对 `STOP`、`CAPTURE`、`REPAIR` 传 `nullptr`，故后者多一条崩溃路径。实测中已因它崩溃过一次，`Eip=00000000`。
2. **不得指挥非己方对象。** 旧 UnitOrder 路径不检查归属，可能崩溃游戏；`Validator` 默认拒绝。受控 Guard 路径在 L0 和 DLL 强制检查归属，`allow_foreign=True` 也不放宽，范围见 Guard 验证记录。
3. **`ProduceOrder` 的 action 被忽略。** 暂停与取消生产须用 `AddEvent` 的 `Suspend`(0xF) 与 `Abandon`(0x10)，载荷为 `production{rtti_id, heap_id}`。
4. **`REPAIR` 被误映射为 `Mission_Capture`**，与占领同义，真维修不可用。
5. **`UNSELECT` 与 `TRY_TO_DEPLOY` 未实现**，调用必抛 `invalid unit action`。
6. **`GameState.map_data` 从不填充**，地图只能经 `ReadValue` 取一次。
7. **`parse_map_data_interval` 设为 0 会被强制改回 1**，且调大反而使单帧变大。
8. **`cmd /c start` 从 WSL 启动游戏会静默失败**，须用 PowerShell 与绝对路径。
9. **测试助手容易写错默认参数**，造成测试假通过。写测试时逐项核对传入值。
10. **profile 的 `--patch` 覆盖层加不了新条目。** 裸写一条新插件报 `entry "mcp-ra2" not found`；要新增必须用 `- insert:` 语法，`insert` 下列条目。
11. **`dsh-headless` 基座的 profile 开不了 Web UI。** headless 是一次性 CLI app，`pnpm dsh --profile X` 会报「a task is required」。要用 GUI 就得选 `dsh-web-app` 基座。
12. **对局会话别把 `reasoningEffort` 设 high。** 一次对战任务的 COT 会把终端刷到不可读；工具调用型任务用 low/medium 足够。
13. **模型写不进目标仓库时，让它交补丁而不是放弃。** 离线会话的沙箱边界是它自己的会话 cwd，`ra2-agent` 可能只读；实测那次的模型把改动做成补丁交付并自验，效果很好。
14. **手抄长字符串容易错一个字母。** 用脚本按短锚点替换，并用 `count` 断言出现次数；作者自己在替换 `Stance.AGGRESSIVE` 时打错过一次。
15. **preset 的 `plugins` 是完整清单，不能引用别的 preset。** 所以 `ra2` 只能整份抄 DSH 的 `cordis`，DSH 升级不会自动跟进；抄写交给 `dsh/generate.py`，用 `--check` 查同步。
16. **`tasklist.exe` 的输出是 GBK。** 严格按 UTF-8 解码会抛 `UnicodeDecodeError`；没匹配时它打的是一行本地化提示（解出来是乱码），故解析只能认以 `"` 开头的 CSV 行，其余一律忽略。
17. **改了 `src/ra2agent/` 的源码或 `dsh/` 里的预设，跑着的 DSH 都还是旧的。** 让 DSH 重载一次，且**要重启 DSH，不要用「关掉 bundle 再打开」热换**——热换会新建一个修订版，而旧修订版只要还有会话绑着就不回收，于是留下第二个跑旧代码的 MCP 进程。关掉那些会话或重启即可回收。`kill` 没用：mcp-client 会自动重连，一秒内补一个回来。

## 环境

- 在 WSL 内运行，**只用标准库**，至今未安装任何第三方包。
- WSL 为镜像网络模式，可直连 Windows 上只监听 `127.0.0.1` 的服务。
- 游戏从 `D:\Games\ra2probe` 启动，失焦即暂停主循环；恢复焦点用 `tools/winfocus.py reset`（Agent 在场时用 `game focus`）。
- DSH 侧只有 `web` 一个 profile（`~/.dsh/profiles/web`），其中装了 bundle `@local/ra2-preset`（软链到本仓库的 `dsh/`）。启动 command 一律在 `deepseek-harness` 目录用 `pnpm dsh --profile web ...`；bundle 从该安装目录解析。
- 操作流程见[真机测试手册](../notes/验证/真机测试手册.md)，环境事实见[开发环境](../notes/环境/开发环境.md)。
