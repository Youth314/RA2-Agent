## 问题、对象与范围

首组只回答三项问题：Beta 的 Grizzly Battle Tank（MTNK）锁定合法敌方 Allied Construction Vehicle（AMCV）时，Object.actual_target 的 RTTI/native ID/类型/指针是否属于该当帧对象，Observer 是否投影为采集连接内合法 Agent ID；AMCV 展开为 GACNST 后，旧车辆引用是否退出回读并正确处理清空/不可观测/新建筑目标；对同一 MTNK 单次 Stop 后是否捕获 Target 清空或重新接敌的真实状态。第三项只测 Target 变化，不重复既有 Grizzly Stop 效果对照，不承诺永久无目标。

受试 MTNK 属于现有 Beta（Americans），AMCV 属于现有 Alpha（Alliance）；不改名册阵营。MTNK 的移动攻击特性不作为差异变量，本单不代替[U02 的 GI 对照](../../notes/验证/U02移动模式在线对照.md#受控复现操作单未执行)。优先由用户人工准备和操作，主持侧只读；若使用已有 Beta 玩家 agent，所有模型单位动作只经正式技法，主持侧不接管 Beta、也不建立普通子 agent 伪装玩家。

本组不主动击毁 AMCV。通过展开制造旧车辆指针退出及新建筑出现，不能据此宣称死亡、灰雾、隐形/伪装、指针复用、所有槽位重排或其他型号通过。准备期间的建造/生产是人工场景准备，不能计入 U08 输入证据；当前只读字段支持不代表受控 Attack 已完成。

## 实验前置门

- 游戏：两侧使用既有 target-v1 产物及原配置，stage=2、帧推进、局次不变；不调用 render/up、不改 FogOfWar、single_step、显示设置或 DSH/preset。加载结果已有证据，本单只检查运行前置，不重新起局重复验收。
- 操作方：每实例只有一个单位命令执行者。用户维持 Alpha AMCV 未展开且静止，并在 Beta 准备一台普通未升级 MTNK；关闭自动部署、自动开局、接战及其他自动改令来源应通过现有会话方式完成，若无法隔离则停止，不静默修改配置。使用玩家 agent 时须确认其真实 Beta 工具作用域；无法确认则采用人工操作。
- 场景：空旷同高地面、无遮挡、不贴桥墙、无其他火力和目标。MTNK 与 AMCV 都存活、在地图、非 limbo、无载员/伪装/隐形或变身过渡；下令及采样窗口重查归属与身份。AMCV 开始健康 1000，动态步骤前建议健康不低于 700；不足时先停止该窗口，不以继续攻击或盲目重发补证。
- 几何：原版 rulesmd.ini 的 MTNK 为 Sight=8、Primary=105mm，[105mm] 的 Range=5、ROF=60；AMCV 为 heavy、Strength=1000、无 Primary/Secondary，DeploysInto=GACNST。基线把 MTNK 放在距 AMCV 大于 10 格的空地并记录 NONE；随后人工移到距离约 4 格。距离以实际 lepton 坐标复核，目标在当帧合法可见集合且画面证实可接战，不以 status 出现或预期路径代替实际射程。
- 身份：玩家动作的 actor/target ID 仅取自 Beta 同一个玩家会话的当前 status。采集器有独立 IdentityTable 和 identity_namespace，其 Agent ID不能传给玩家 call；Alpha 的 ID也不能当 Beta 目标 ID。主持诊断可用 Alpha 己方 native_id 核对 Beta 已合法导出的引用，不能将对侧信息补进 Beta Observation 或作为隐藏目标回退。

规则、单位模式或前置不符则停止，保留未执行/场景无效；运行中 raw 版本不符、读取错误、帧重置、崩溃报告变化或未知排队请求也立即停止新动作并留证。MTNK 自动锁定可能先于点击或 focus_fire，因此先采样已有目标；preexisting 的 OBJECT 可支持回读正确，不能证明本次新输入。

## 最小操作顺序

| 窗口 | 操作 | 采样与结束条件 |
|---|---|---|
| B0 身份与基线 | 用户在 Beta 准备/选中唯一受试 MTNK；Alpha 保持初始 AMCV。MTNK 在 10 格外静止，不发实验攻击 | 保存两侧身份、模式、位置、健康及 Beta 的 NONE；目标稳定、两侧帧推进后进入 B1 |
| B1 非空目标 | 用户只移动 MTNK 到约 4 格。已自动锁定则直接只读记录；需要显式攻击时在人工目标点击与下述玩家技法中选一种，仅一次 | Beta raw=OBJECT、RTTI=52、object_type=Unit(1)，引用与 Beta 当帧合法 AMCV 指针一致、native ID 位模式与 Alpha 己方 witness 一致；采集 Observer 投影的 object Agent ID 属于该连接可见集合。覆盖至少一个 ROF 窗口，画面开火或 Alpha 健康下降单列为原版动作证据；无法合法回读则不反复下令 |
| B2 变身前释放 Agent 任务 | 若使用玩家技法且任务仍在管，Beta 玩家仅 cancel 本次 focus_fire，等待确认租约释放；人工方式没有 Agent 任务 | cancel 不发 Stop、不以取消改变原生目标；先结束 Agent 任务，避免 target 消失后的 focus_fire 旧 Hold 分支干扰 B3 |
| B3 目标车辆退出 | 确认 B1 的合法非空目标证据与健康门后，用户在 Alpha 对该 AMCV 按一次 D 展开；不同时下其他指令 | 记录旧 AMCV 从对象集合退出、新 GACNST 出现以及 Beta Target 的连续状态。NONE/UNOBSERVABLE 均不得带旧载荷；新 OBJECT 必须映射当帧合法 GACNST、类型 Building(6)、新 native ID/指针。Agent ID 的启发式延续不能作为旧引用有效的证明；旧车辆已消失后仍导出其 OBJECT 为失败。至少记录退出前后各一段推进帧 |
| B4 单次停止与尾窗 | 用户对同一 MTNK 按一次 S，或 Beta 玩家通过正式 stop 调一次；二选一，不重复 | 记录 Idle/Stop 输入与随后 Target。捕获 NONE 支持该帧已清空；未捕获 NONE 保留清空未证，不用 Stop 回执替代。之后可自动重新锁定 GACNST，须按新合法身份判断，不算永久驻守失败或盲目再停 |

各窗口结论分别记通过、失败、无法确认或场景无效。一次错误/超时不证明输入未执行；先只读回查，不重复 Attack、Stop 或 D。B1 未取得合法非空目标时不执行 B3；健康或其他前置失效时结束该窗口。操作方在收到对应窗口就绪提示后再动作，不因等待时间经过推定已经操作。
