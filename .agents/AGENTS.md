# .agents

与开发 agent 有关的一切内容。读者是 agent。给人看的文档在 [docs/](../docs/AGENTS.md)。

索引链：根 `AGENTS.md` → 本文件 → 具体文档。

## 目录

| 目录 | 用途 |
|---|---|
| `notes/` | 文档：计划、指南、决策记录。暂不分层，有真实需要再分 |
| `drafts/` | 草稿：任务交接、备忘等。不必成为正式文档，要求宽松 |
| `tmp/` | 临时产物：脚本、截图、日志。可随时删除，不入库 |
| `skills/` | agent skill，格式同 DSH |

## 写作要求

适用于 `notes/` 与 `docs/`；`drafts/` 与 `tmp/` 不适用。

- 禁用口语
- 精简不失要义：删词前保留每个命题的主体与动作、条件与时序、模态、例外、后果；字数减少本身不是改进
- 同一事实单源记录，别处链接
- 只写当前状态，历史留在 git
- 每段一行（便于 diff）

## 工作流

改动项目内容前：查相关文档 → 读文件 → 完成后回写文档（修订或新增）。
