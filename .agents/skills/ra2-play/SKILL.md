# 打红警 2

**开局前先读这一页。** 单位、造价、克制这些数字**不在这里**，在 `codex/`——查表见文末。

路径都相对仓库根 `~/ra2-agent`。

## 一局的循环

1. **`status`** 读局势。每次醒来先看它；新结果与告警只报一次，读过就没了。
2. **`tactics`** 看此刻能用哪些技法。卡片按局面筛过——没敌人时不会出现接战技法。
3. **`call`** 下达任务。立刻返回受理结果，**不等生效**；成没成由下一次 `status` 报。
4. **跟进**。有任务在飞就短看，空闲就长看。别在 `call` 之后干等。
5. **汇报**。每进行几步（三到五步）用中文汇报一次：局面、做了什么、下一步。别攒到最后一起说。
6. **复盘**。这一局哪些判断错了、缺哪条技法。

**出事会被叫醒**：掉单位或建筑、电力不足、被渗透、出局、建筑完工待放置，都会以一条新的 user 消息把你叫回来——那是唤醒，不是有人在跟你说话。收到就先 `status` 看现状再决定。唤醒有额度（一局限次、两次之间有最小帧距），故常规的事仍靠自己的查看节奏，别指望它。

**坐标不要自己算**：建筑放哪儿，`status` 的「待放置」段按**方位与距离**给了可选落点（如「西 6 格（2–5 格外）」），挑一格的坐标传 `cell` 即可；不给 `cell` 则由 L0 问引擎要一格最近的合法格。推进的单位目标格由你决定，但不可通行与图外的格子会在受理点被拒——不必自己预判地形。

## 单人对局：起游戏

游戏没开就先 `game status`，再 `game start`。窗口失焦会暂停主循环（帧号不涨但连接还在），用 `game focus` 抢回来。

## 主持一局对战：先起整局，再派玩家

一局对战是**多个游戏进程**，不是多个调用方连同一个进程。`-SPAWN` 不进大厅也不等对手，游戏自己在加载界面等连接，所以**只起一个实例的后果是它在加载界面干等约 60 秒再判对方掉线——两边都进不去**。

起局用仓库里的启动器，它按 `config/match.json` 的名册一次起全，并且**等到每一方都进对局才返回**：

```sh
python3 tools/start_match.py up        # 先渲染配置，再起全并等就绪
python3 tools/start_match.py status    # 逐参与者看进程、端口、阶段、帧
python3 tools/start_match.py down      # 按 PID 停（不会误伤另一方）
```

**别手改 `spawn.ini`。** 每方目录里那份是**渲染出来的**：`up` 会按名册与规则重新生成两份（原文件留成 `.render-bak`），镜像字段（名字、阵营、颜色、对局端口）全部从名册推导——手改迟早让两边漂。要改就改 `config/match.json`：

- **`players`** = 部署事实：名字、游戏目录、探针端口、对局端口、`Side`、`Color`。**只有名册里的人才能参战**，加人要加在这里。
- **`rules`** = 每局的选择：地图、资金、`TechLevel`、迷雾、箱子、`UnitCount`、AI 席位…… 也可以临时覆盖：

```sh
python3 tools/start_match.py up --rule credits=20000 --rule fog_of_war=Yes
python3 tools/start_match.py render --dry-run     # 只看会写成什么，不落盘
```

**换地图还没打通**：`rules.scenario` 只是个文件名，游戏读的是它指向的那份文件的内容；目录里的 `.mmx` 是二进制容器，得先把图解出来备好。**现在换 `scenario` 而没有对应文件，两边都会起不来。**

地图还有席位上限——`spawnmap.ini` 的 `[Basic]` 里 `MaxPlayer` 是多少就最多几个人，超了会崩。

**玩家的工具面是分开的**：每个玩家由另一个 agent 扮演，它只拿得到自己那一方的工具——这是**构造上**的隔离，不是口头约定。所以不要自己 `subagent` 建一个再叫它「当 Beta」。派玩家的具体工具见 [双实例联机](../../notes/双实例联机.md)。

**主持 agent 在信任边界之外**：它手里也有游戏工具（连着名册里的第一方），因为它要用 `game` 看进程。它不该用那些工具替任何一方下令——那由你（人类）看着。

## 三条硬规矩

- **任何对局动作都必须经过技法。** 没有直接向引擎下命令的工具。
- **单位一律用 `status` 里给出的 id。** 名字只是给人看的，指针会变。
- **对战时不写技法。** 要写去读 `ra2-write-tactic`。
