# 开发环境

## 运行位置

工具与适配层**全部在 WSL 内运行**，不在 Windows 侧。

WSL 为镜像网络模式（`C:\Users\Youthz\.wslconfig` 的 `networkingMode=mirrored`），故 WSL 可直接连到 Windows 上只监听 `127.0.0.1` 的服务。实测服务端绑在 Windows 的 `127.0.0.1:14521`，WSL 用 `ws://127.0.0.1:14521` 直连成功。

因此不必把脚本复制到 Windows，也不必用 Windows 的 Python。

## Python

WSL 侧为 Python 3.14，**只用标准库**：protobuf 与 WebSocket 均手写，不需要 `protoc`、`google.protobuf` 或 `websocket-client`；测试用标准库 `unittest`。Python 适配层未安装第三方包；S3 的系统 C++ 构建工具与 DLL 依赖单独记录在[DLL 构建准备](DLL构建准备.md)。

```sh
cd ~/ra2-agent
PYTHONPATH=src python3 -m unittest discover -s tests -t .
```

`PYTHONPATH=src` 是必需的（尚未 `pip install`）。`tools/` 下的脚本多数还引用旧的 `ra2client`，需 `PYTHONPATH=src:tools`；`tools/winfocus.py` 是 `ra2agent.deploy.winfocus` 的转接层，自己把 `src` 放进 `sys.path`，故手册里的 `python3 tools/winfocus.py reset` 不带 `PYTHONPATH` 也能跑。

## Windows 侧

| 路径 | 用途 |
|---|---|
| `D:\Games\ra2probe` | 探针游戏环境：硬链接的 MIX 与复制的可执行文件 |
| `D:\Games\ra2patch` | patch 工作目录，含 `patch_gamemd.py` 与上游源码 |

Steam 原始安装目录除 `RA2MD.INI` 的分辨率设置外未被改动。

## 启动、焦点与诊断

启动命令、进对局的判据、焦点处置、崩溃留证与坑清单见[真机测试手册](../验证/真机测试手册.md)。

失焦暂停与恢复方式取决于显示配置；当前限制及 cnc-ddraw 后台推进条件见[真机测试手册](../验证/真机测试手册.md#三焦点最容易踩的坑)。发生焦点暂停时，同步观测仍可用，恢复需实际焦点切换，可用 tools/winfocus.py reset。
