# 原版事件接口验证

日期：2026-10-02。范围：S3 第一部分，只读原版事件输入接口。当前已实现并离线验证；未新增游戏命令、公开技法、DLL 字段或强执行回执。原版人工效果与单位差异以[能力表](../引擎/玩家操作能力表.md#s2-现场记录)为准。

## 实现与调用边界

[NativeEvent / NativeMission / NativeTarget](../../../src/ra2agent/engine/native_events.py) 解析 GameState 的 out_list、do_list、megamission_list。对象为 frozen dataclass，保留事件类型、house_index、帧、timing、is_executed、来源列表、原始 Event 字节及对应 MegaMission 载荷；不发送命令。仅当 event_type=4 / 5 时读取各自的 oneof，其他事件与未知载荷保留原始字节但不推断任务；已知字段线类型错误抛 ProtocolError。

[GameState](../../../src/ra2agent/engine/state.py) 保存解析结果，公共 native_events 属性只返回唯一 current_player 的 house_index 对应事件。不存在唯一玩家时按既有 player_house 契约拒绝查询；旧状态没有事件字段时返回空 tuple。内部原始列表仍保留供 L0 诊断，不向模型工具目录或 status 增加原始事件。GameState.raw 的现有保留行为不变；公共视图过滤不是针对任意 Python 技法的沙箱隔离。

NativeTarget 的 m_id / m_rtti 沿用原版编码，is_null 仅依据 m_rtti=0，不能因 m_id 非零就视为对象目标。cell 仅对 RTTI=11 且非负编码解码 x + 1000*y，不证明地图合法性；RTTI=52 的对象目标不能解释成 pointer、array_index 或 Agent ID。缺失子消息为 None，空子消息保留 proto 默认值；MegaMission_F 的 speed / max_speed 不误解析为 follow。

接口保留重复列表槽和原始事件帧，不进行逻辑命令计数或去重。is_executed 仅为上游元数据，不表示某个 Agent 请求的 applied；输入事件、对象持续 Target / Follow 与任务结果是不同观测。当前 DLL 未提供 Idle 的对象载荷，接口不伪造 actor；本只读视图不提供稳定身份或当前模式 / 乘员 / 矿量；后续己方原版 ID 关联的实现与限制见[Guard 接口验证](Guard接口验证.md)。

## 离线证据

永久测试为[原版事件测试](../../../tests/test_native_events.py)，九个真实 Event 样本保存在[样本及来源指纹](../../../tests/data/native_events.json)。样本来自 S2 Alpha 录制，只截取事件字节；GameState 信封、MegaMission_F、错误 oneof / 线类型和带符号值等边界为合成输入，不表示新的真机实验。测试不依赖被忽略的临时日志存在。

相关回归入口：

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m unittest tests.test_native_events tests.test_proto tests.test_state tests.test_observation tests.test_executor tests.test_micro tests.test_autopilot tests.test_command tests.test_mcp tests.test_replay
```

结果：426 项通过，未运行全量测试。覆盖真实 G / 地点 / 单位 / 建筑目标、矿车输入与后续任务区别、维修输入类别、残留载荷、RTTI=0、字段缺失、符号、列表来源和重复、只读对象、当前玩家过滤、无事件旧状态及非法玩家查询；其余模块验证本次 GameState 扩展与现有执行链兼容。

另以正式 NativeEvent.parse 流式复查 S2 Alpha 全部 Event 原始字节：55484 条事件观测、199 条任务事件观测的元数据与原录制相符，135 条残留载荷观测未被误判为任务。上述数量包含相同事件在多次采样与列表中的重复表示，不能作为命令次数。复查没有连接或启动游戏，没有替换 DLL，也不增加原版效果或新下令路径的等价性结论。
