## 已实现边界

`Object.actual_target=22` 是消息包装，`GameState.target_observation_version=19` 声明 v1 只读能力。旧 DLL/旧录制缺字段时保留未提供；包装区分不可观测、无目标及合法对象目标。已同步仓库 ra2yr.proto 的既有 native_id=21、Guard/Stop 版本 17/18 和 action=13–15，保持原 wire 含义；commands_game 的既有扩展仍由完整协议补丁保存。

DLL 只读取己方在场、存活、非 limbo Techno 的 Target。每帧重建成员索引，非空 Target 先按地址值查当帧成员，不对未知目标地址调用 WhatAmI 或读取成员；具体类型复用固定 ABI WhatAmI，ID 来自 UniqueID，事件式引用保持 RTTI=52、具体类型另列，ID 的 int32 wire 保留 uint32 位模式。外方 actor 的 Target 不读取、不导出，外方 Object.native_id 仍不提供；Cell 和其他类型目标只返回不可观测。

外方目标须通过 Scenario、Rules、Session 的 FogOfWar 全关闭、合法目标格已探索、未隐形且未伪装的保守门；缺上下文、灰雾、未知隐形状态和伪装均不可观测。使用与 parse_Cell 相同的 AltFlags 0x8 来源，不调用依赖视口的 IsVisible 或把已发现标记视为当前视野。此门已通过离线策略检查，运行时字段语义仍待限定真机核对，不声明灰雾/隐形/伪装目标支持。

复用 protobuf 槽位时，在对象解析开始及目标填充时清除 actual_target，NONE/UNOBSERVABLE 不携带旧引用。成员解析和策略分开，纯策略头文件进入完整引擎补丁；没有新增游戏输入路径。`commands_game.cpp` 与已验 Stop 源码逐字节一致。

Python `ActualTarget` 严格校验 wire、状态组合、对象类型、引用 RTTI 和 native ID；Object/GameState 启用有边界的 strict protobuf 解析，拒绝截断被误解释成合法无目标，其他协议调用保持原默认解析。L1 使用 `Observation.actual_targets[actor_agent_id] -> ObservedTarget(status, agent_id)`，其中 status 为 not_provided/unobservable/none/object，只有 object 带合法目标的 Agent ID。投影要求 actor/target 身份为当帧、目标在合法对象集合，己方目标还须匹配 native_id；失踪宽限、变身、指针复用或缺身份不能恢复旧目标。Observation 的己方、可见敌方与中立 GameObject 均清除原始 actual_target；底层 state 仅作诊断，不作为隐藏目标投影的回退路径。

当前目标匹配不等于新输入、射程内、开火、击毁或任务完成。Executor 的 Attack 判据、focus_fire 和 guard_area 未改；受控 Attack 的合法目标受理、服务端身份复查和结算仍是下一切片。版本缺失不回退 Mission.ATTACK 来证明指定目标。
