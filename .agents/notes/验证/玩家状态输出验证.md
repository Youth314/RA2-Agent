## 输出契约

己方与 observation.visible_enemies 的对象行增加 health，文本为“健康 N”，数值只表示当帧当前健康，不推断最大值。隐藏对象不从完整 state 补列，不展示敌方实际 Target。

己方对象行增加 actual_target={status, agent_id}，只取 Observation.actual_targets 的合法投影，不回退到原始 Object.actual_target。object 的 Agent ID 必须仍属于当前合法、存活、在场且非 limbo 的己方/可见敌方/中立集合；否则输出 unobservable。原始 pointer、native ID 与目标命令身份不进入新增文本。

| status | 文本 | agent_id |
|---|---|---|
| object | 实际目标 #ID | 当帧合法 Agent ID |
| none | 实际目标 无目标 | null |
| unobservable | 实际目标 不可观测 | null |
| not_provided | 实际目标 未提供 | null |

旧 DLL、未提供投影时记 not_provided，不能用缓存或原始引用补为 object / none。未知投影状态按 unobservable 处理；非 object 状态清除 Agent ID。

新结果文本增加 completion_basis：operation_observed 标“本次操作已观察”，goal_satisfied 标“目标条件已满足”，未提供依据明确标“未提供”。保留 satisfied / 计数与 unknown 提示，不将一次操作完成解释为抵达、击毁或持续接战。新结果仍只报一次，单位释放与 cancel 行为沿用既有实现。

在管任务和新结果只显示最近一条 receipt / evidence 及其采样 frame。Attack 观测文本按允许字段选择 native_input、actual_target、target_status 与相应观察帧；忽略其余诊断字段和 input_timing。unconfirmed / unobserved 不附可能残留的旧匹配帧，不给缺失证据补默认成功。内部完整日志未被修改，模型 MCP 输出仍为文本，不新增工具。
