# 技法框架

L0 只做基础设施，其上的能力由模型自己写成**技法**（tactic），按需组合。层的边界事先定不出来，改由组合与封装自然形成。

## 三层

| 层 | 名称 | 时间尺度 | 决策者 | 产出 |
|---|---|---|---|---|
| 0 | 基础设施 | 游戏帧 | 固定代码 | 引擎命令 |
| 1 | 技法 | 每 tick 22–45 帧 | 模型与人离线写，运行时确定性执行 | 意图 |
| 2 | 指挥 | 模型自定 | LLM；人经对话介入 | 选技法、给参数、定目标 |

**技法层不依赖模型的调用节奏。** 模型不发话时，已下发的技法照常推进。逐帧轮询不值（单帧观测 11.9 KB），且寻路与自动开火由引擎负责。

## 意图与技法

**意图是要什么，技法是这样做。** 两个方向的词汇不同：

| 方向 | 形态 | 理由 |
|---|---|---|
| 指挥 → 技法 | 通用信封：技法名 + 参数 + `scope` + TTL | 模型要能加新能力，封闭的 kind 集合会把它挡死 |
| 技法 → 基础设施 | 类型化封闭集合：`MoveTo`、`Hold`、`Attack`、`Produce`、`Place`、`Sell` | 对应固定的引擎能力，类型约束能在发送前拦错 |

指挥层意图复用 `Intent` 信封（`id`、`parent`、`layer`、`issuer`、`scope`、`created_frame`、`ttl_frames`、`state`），载荷为 `TacticCall{tactic, params}`。

## 接口

```python
class Level(StrEnum):
    NORMAL = "normal"      # 正常玩法
    EDGE = "edge"          # 时序与边界技巧，人也能做
    EXPLOIT = "exploit"    # 明确 bug，人难复现
    CHEAT = "cheat"        # 只有 Agent 做得到：读全图、伪造事件、直接加钱

class Mode(StrEnum):
    MATCH = "match"        # 对战：只看卡片
    OFFLINE = "offline"    # 离线：卡片加 L0 的 API 与源码

@dataclass(frozen=True)
class Param:
    name: str
    default: object
    help: str
    check: Callable[[object], bool] | None = None   # 取值检查，受理时执行

# 内置检查：is_cell、is_stance、is_non_negative_int、is_positive_number

@dataclass(frozen=True)
class TacticInfo:
    name: str                        # 唯一名，模型按它引用，如 "advance_to_cell"
    summary: str                     # 一句话，进卡片
    layer: Layer = Layer.L1_TACTIC
    params: tuple[Param, ...] = ()
    requires: tuple[str, ...] = ()   # 适用条件标签
    level: Level = Level.NORMAL
    expose: bool = True              # 是否进对战时的卡片；零件设假
    source: str = "builtin"          # builtin / model / human
    version: int = 1

@dataclass(frozen=True)
class Tactic:
    info: TacticInfo
    run: Callable[[TacticContext], tuple[Intent, ...]]

class TacticContext:
    """一次调用拿到的全部东西。技法只读，不做 I/O，只返回意图。"""
    observation: Observation         # 尊重迷雾的一帧
    subject: Squad                   # 本层管的对象，只读
    params: dict                     # 本次调用的参数
    frame: int                       # 当前游戏帧
    attempt: int                     # 第几次尝试，卡住重来时递增
    memo: dict                       # 跨帧记事本，按技法与键隔离，任务结束清空

    def call(self, name, *, optional=False, **params) -> tuple[Intent, ...]:
        """调用另一条技法。必须经此，门控、适用条件、深度与调用链日志都在此生效。
        `optional=True` 只放行适用条件，不放行等级门槛。"""

    def intent(self, cls, *, scope=None, **payload) -> Intent:
        """造一条给基础设施的意图：层、帧号、涉及对象自动填好。"""

class TacticRegistry:
    def register(self, tactic: Tactic) -> Tactic: ...
    def load_builtin(self) -> TacticRegistry: ...            # 返回自身，便于连写
    def cards(self, mode, observation=None, subject=None) -> list[Card]: ...
    def run(self, name, *, observation, subject, params=None, frame=0, memo=None,
            log=None, attempt=0) -> tuple[Intent, ...]: ...
    def catalog(self) -> str: ...        # 人类可读清单
    def fingerprint(self) -> str: ...    # 库指纹，写入决策日志

@dataclass
class TacticPolicy:
    max_level: dict[Layer, Level]    # 每层的等级门槛
    enabled: frozenset[str]          # 空集表示不额外限制
    disabled: frozenset[str]
    max_depth: int = 8               # 调用链深度上限
    max_calls: int = 32              # 一次顶层调用的技法次数上限
    max_intents: int = 32            # 一次顶层调用的意图数上限
    timeout_ms: int = 50
    def allows(self, info: TacticInfo) -> bool: ...
```

## 安全

| 机制 | 做法 |
|---|---|
| 等级判据 | 对称性：人类在同一版本、不开挂能做到的算技法；只有 Agent 因能读内存、注入事件才做得到的算作弊 |
| 两道闸 | 上下文闸（不进卡片）加执行闸（调用时报错，不静默跳过） |
| 等级穿透 | 有效等级取整条调用链的最大值；内层调用必须经 `ctx.call`，不得直接 import |
| 深度与环 | 调用深度上限；调用链内同名即拒绝 |
| 意图总量 | 一次顶层调用产出的意图数上限 |
| 异常隔离 | 技法抛异常只废掉这一次调用，记录后继续 |
| 运行时限 | 深度与总量在代码层限死；墙钟超时用 `SIGALRM`（运行时位于主线程时有效），否则退化为耗时统计与连续超时停用 |
| 静态检查 | 技法源码只许白名单 import；禁 `open`、`eval`、`exec`、网络与进程 |
| 不碰引擎 | 技法只返回意图，下发一律经 `Validator` 与 `Executor` |

## 可见面

| 模式 | 模型能看见 | 能做什么 |
|---|---|---|
| 对战 | 顶层卡片：名字、一句话、参数、适用条件 | 发指挥层意图 |
| 离线 | 卡片加 L0 的完整 API 与源码 | 读写技法库、离线验证、注册新技法 |

## 技法状态

`subject` 只读，技法不改状态；状态由运行时按返回的意图与观测更新。需要跨帧记忆时用 `ctx.memo`，按技法与键隔离，任务结束清空。

## 运行时

技法只回答「这一步该下什么命令」，运行时（`micro.py`）负责其余：

| 事项 | 规则 |
|---|---|
| 下令时机 | 只给「还没下过令」或「卡住要换路点」的单位下令，不重复下发 |
| 到位 | 与目标格的切比雪夫距离不超过宽容（默认 1 格，引擎在目标格被占时会停在邻格） |
| 卡住 | 位置连续 90 帧不动即换路点，`ctx.attempt` 加一，技法据此换落点；超过重试上限判失败 |
| 命令失败 | 对象消失或 mission 非法：该单位失败；其余服务端错误：整队失败 |
| 超时 | 记账重试，超过上限该单位失败 |
| 窗口失焦 | 整拍挂起，不判失败，帧恢复后继续 |
| 结算 | 有一条到位即 `satisfied`，一个都没到位即 `failed`；TTL 到期记 `expired` |

结算记录进决策日志，也留在运行时里供上层查询。

## 生命周期

草稿 → 静态检查 → 离线回放验证 → 注册进库 → 统计使用与成败 → 废弃。

每条技法带 `version`；一局开始时把库指纹写入决策日志，复盘可重现当时的能力集合。

## 示范技法

| 名 | 说明 | 等级 | 暴露 |
|---|---|---|---|
| `advance_to_cell` | 把这队单位推进到目标格附近，先展开队形 | normal | 是 |
| `hold_position` | 原地驻守 | normal | 是 |
| `engage_nearest` | 半径内最近的可见敌人，停下开火 | normal | 是 |
| `advance_covering` | 组合示范：先接战判定，无敌人再推进 | normal | 是 |
| `halt` | 停止这队单位；零件，只供组合调用 | normal | 否 |
